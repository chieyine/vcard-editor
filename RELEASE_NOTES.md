# vCard Editor 0.1.0

Released 2026-08-11 · Phase 7 beta launch foundation

This release provides browser-local vCard editing, conversion between VCF/CSV/Excel and JSContact/jCard/xCard/LDIF, cleanup and validation tools, compatibility fixtures, accessibility foundations, an offline PWA shell, SEO content, and production launch controls.

Analytics and advertising are disabled by default. Preview deployments are protected from indexing. See [DEPLOYMENT.md](./DEPLOYMENT.md) and [LAUNCH_CHECKLIST.md](./LAUNCH_CHECKLIST.md) for the operational handoff.
